## var, let, const 차이

자바스크립트에서 var, let, const는 모두 변수를 선언하는 키워드지만, 스코프와 재할당 가능 여부, 호이스팅 동작에서 큰 차이가 있습니다. 현대적인 코드에서는 var는 거의 쓰지 않고, 변경 가능하면 let, 변경 불가능하면 const를 쓰는 것이 권장됩니다

상세 설명
- var
- 함수 단위 스코프를 가짐 → if, for 같은 블록을 무시하고 함수 전체에서 접근 가능.
- 같은 이름으로 여러 번 선언 가능 → 유지보수 시 혼란을 초래할 수 있음.
- 호이스팅 시 undefined로 초기화되어 의도치 않은 동작 발생 가능.
- let
- 블록 단위 스코프 → {} 안에서만 유효.
- 중복 선언 불가, 하지만 값 재할당은 가능.
- 호이스팅은 되지만 초기화 전 접근 시 Temporal Dead Zone(TDZ) 에러 발생.
- const
- 블록 단위 스코프.
- 선언과 동시에 초기화해야 하며, 재할당 불가.
- 단, 객체와 배열은 참조값만 고정 → 내부 속성이나 요소는 변경 가능.

실무에서의 권장 사용
- 기본적으로 const 사용 → 값이 변하지 않는다는 의도를 명확히 전달.
- 값이 변할 가능성이 있을 때만 let 사용.
- var는 사용하지 않음 → 예측 불가능한 동작을 유발할 수 있음.
